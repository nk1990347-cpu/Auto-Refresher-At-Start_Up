## ✨ Key Specializations & Features

* **🔒 100% Offline & Lightweight:** Operates locally on your machine with zero external network connectivity or data logging.
* **⚡ Dual Mode Operation:**
  * **Manual GUI Mode:** Customize your refresh count, apply settings, or exit through a sleek, dark-themed control panel[cite: 3].
  * **Silent Startup Mode:** Configures a custom batch launcher (`.bat`) inside the Windows Startup folder to silently refresh your system immediately after system boot[cite: 3].
* **🖱️ Smart GUI Interaction:** Automatically minimizes open windows using `Win + M`, targets the desktop canvas, and executes right-click desktop refresh routines based on user-defined loops[cite: 3].
* **🎨 Modern UI & Change Tracking:** Features dynamic tooltips, visual status alerts, and smart unsaved-change tracking (Apply / OK / Cancel)[cite: 3].
* **📦 Portable & Standalone:** Packaged into a self-contained executable file with built-in asset and icon discovery[cite: 3].

## 🚀 How to Use

1. Download the latest **`AE-Creation.-.Auto.Refresh.exe`** from the [Releases Page](https://github.com/nk1990347-cpu/Auto-Refresher-At-Start_Up/releases/tag/V1.0.0).
2. Double-click the `.exe` file to launch the **GUI Control Panel**[cite: 3].
3. Set your desired **Refresh Count** (default: `5`)[cite: 3].
4. **(Optional)** Check **Create Start-up Folder** and click **Apply** to enable automatic background refreshing every time Windows starts up[cite: 3].
5. Click **OK** to save changes and exit[cite: 3].
